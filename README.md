# cardsynccore.com

The public website for CardSync Core, served by GitHub Pages from this
repository's `main` branch (custom domain in `CNAME`). Plain HTML and one
stylesheet; no build step.

It is a static copy of the landing pages in the (private) app repository,
rebranded and trimmed for a product in private development: no sign-up,
log-in or pricing yet. When the app moves to its own server, the site moves
with it and this repository can be archived.

DNS for `cardsynccore.com` is at GoDaddy: four `A` records for the apex
(GitHub Pages' addresses) and a `CNAME` for `www` pointing at the GitHub
Pages host.
